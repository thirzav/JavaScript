# JavaScript

In this repository you can find various exercises done with JavaScript. 

    1. Exercise billing system:

For this exercise, I made a basic visual billing system. It’s a pretty simple version where users can enter customer details and items they’re buying. It adds up the prices, calculates tax, and shows a basic total at the end. It’s definitely a rookie attempt, but it helped me get the hang of things like handling user input, doing basic math, and putting together a simple interface. Nothing fancy, but it was a good starting point!


    2. Exercise password

For this exercise, I created a simple password check feature. It makes sure that the password contains at least one capital letter and one number. It’s a basic validation to help ensure passwords are a bit stronger. I focused on making it easy to use and understand, with clear feedback if the password doesn’t meet the criteria. Nothing too complex, but it was a good way to practice working with strings and conditions!

    3. Recipe Website

For this project, I built a recipe website where the page dynamically creates recipe cards based on the number of recipes stored in an array. Each time a recipe is added, a new div is automatically generated to display it. On the homepage, I also included a cool feature where three highlighted recipes change every time you refresh or enter the page. It’s all done with JavaScript, and it helps make the site feel a bit more interactive and fresh each time you visit. It was a fun way to practice working with arrays, dynamic content, and JS functionality!
